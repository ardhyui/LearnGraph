# Roadmap LearnGraph

Backlog prioritas untuk perbaikan otomatis (satu item per putaran, rutin tiap jam).
**CI = lokal `npm run ci`** (tanpa GitHub Actions, sesuai keputusan pemilik): npm ci bersih,
typecheck, lint, test, build, smoke test Playwright dengan PGlite. Wajib hijau sebelum setiap merge.

Urutan (sejak 2026-11-01): fondasi keamanan & lint sudah beres, jadi **produk yang dirasakan pelajar didahulukan** — onboarding, alur belajar di dashboard, UX/copy, tampilan mobile, aksesibilitas, performa. Hardening hanya bila ada bug/risiko nyata. Item yang butuh akun,
secret, atau keputusan biaya dari pemilik ditandai 🔒 dan dilewati sampai ada keputusan.
